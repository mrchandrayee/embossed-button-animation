A standalone recreation of the uploaded 22-second screen recording.

## Effects visible in the source video

The recording is titled **Embossed Button Animation**. It shows a vertically stacked set of two-column cards: a light neumorphic button preview on the left and the CSS snippet on a dark code panel on the right.

The seven named effects visible in the video are:

1. Slide Down
2. Slide Up
3. Diagonal Sweep
4. Expand X
5. Expand Y
6. Split Slide
7. Corner Grow

The first two snippets visibly use a `#667eea` overlay, `translateY(-101%)` / `translateY(101%)`, and a `.4s cubic-bezier(.25,1,.5,1)` transition. The other examples are implemented to match their visible effect names and previews.

## Run locally

1. Extract the ZIP.
2. Open `index.html` in a modern browser.
3. Hover over each button to see its animation.

No dependencies, npm install, or build tools are needed.

## Files

- `index.html` — page layout and each effect's visible CSS sample
- `style.css` — dark code layout, neumorphic buttons, and all seven transitions
- `README.md` — project notes and run instructions
